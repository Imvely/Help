## 2. 공공데이터 소스

### 2-1. 식약처 식품안전나라 OpenAPI

- 포털: https://www.foodsafetykorea.go.kr/apiMain.do (무료, 회원가입 → 인증키 → 서비스별 활용신청)
- URL 형식: `http://openapi.foodsafetykorea.go.kr/api/{keyId}/{serviceId}/{xml|json}/{startIdx}/{endIdx}`
- **공통 제한**(중요): 1회 최대 1,000건, 증분(CHNG_DT) 미사용 시 시간당 100회, 06~19시 키·서비스당 300회, 증분 조회는 최근 7일분만, 당일 변경분은 19시 이후.
- 결론: **실시간 호출 불가 → 전체 덤프 후 자체 DB 구축 + 일배치 증분** 구조가 필수([03-architecture.md](03-architecture.md) §6).

### 2-2. 수입식품(제조국·수출국) — 수입식품정보마루

- 웹 조회 https://impfood.mfds.go.kr/CFCCC01F01 : 제품명, 수입업체, **제조국, 수출국**, 제조/수출업소, 소비기한, 원재료, OEM 여부, 회수 필터.
- **공식 OpenAPI 없음.** 크롤링은 약관·부하 리스크 → **공공데이터 제공신청**(data.go.kr 제공요청 제도)으로 요청. 민간 SDFI(https://sdfi.co.kr)가 동일 데이터를 가공 제공 중 → 제휴 후보.
- data.go.kr 보조 API: 국가별 수입식품 품목정보(15095361, 품목 단위라 개별 제품 매핑엔 부족), 수입식품업 행정처분(15125111), 해외직구 위해식품 차단(15057831), 반입차단 원료성분(15132686).

### 2-3. 화장품 성분

- **대한화장품협회 성분사전(KCIA)** https://kcia.or.kr/cid/ : 식약처 공동 구축, 표준 성분명·영문·CAS·CosIng 등재 여부. 공개 검색 가능, **대량 API/라이선스는 협회 협의 필요**.
- **식약처 고시**: 「화장품 안전기준 등에 관한 규정」 별표1(배합금지), 별표2(배합한도), 알레르기 유발 착향제 **25종**(2020년부터 표시 의무). 법제처 원문에서 추출(공공 API 없음).
- **제품별 전성분 공공 DB 없음**: 2017년 서울행정법원이 식약처 보유 원료정보를 영업비밀로 판단([판례](https://www.nepla.ai/case/서울행정법원/2016구합81826)). → 전성분은 **라벨/온라인몰 표기 OCR** 또는 자체 구축만 가능.
- **EWG Skin Deep**: 약관상 "기계판독 가능한 형태로 상당 부분을 상업적으로 이용 금지"([ToS](https://tostracker.app/document/ewgorg-tos)). **무단 사용 불가.**
- **CosIng(EU)**: 공개 DB, 인벤토리 export 가능. EU 오픈데이터 라이선스 확인 후 사용.

### 2-4. 바코드 DB

- **코리안넷**(GS1 Korea / 대한상의 유통물류진흥원, https://www.koreannet.or.kr): 880 코드 통합관리. 제3자 API 조건 비공개, 직접 협의 필요. C005 중단 사례로 볼 때 보수적.
- **Open Food/Beauty Facts**: ODbL. 한국 커버리지 매우 낮음.

### 2-5. 알레르기·첨가물·카페인

- 식품 알레르기 의무표시: **19항목**(조개류 굴·전복·홍합을 따로 세면 22종). 목록은 [05-knowledge-base.md](05-knowledge-base.md) §3. C002 원재료명 텍스트에 동의어 사전(예: "난백"→알류)을 적용해 자동 추출 가능.
- 식품첨가물: 식품첨가물공전(식품안전나라 기준규격)에서 품목명·용도 테이블 확보. 구조화 API 없음 → 자체 구축.
- 카페인: 제품별 공공 DB 없음. 고카페인(0.15mg/mL 이상) 음료는 총 카페인 함량 표시 의무 → **OCR로 추출**이 현실적.

### 2-6. 기타

- HACCP 인증 업체 API(data.go.kr 15118080), 친환경 인증(농관원 enviagro), 비건 인증(민간, 기준 상이), 할랄(KMF), Leaping Bunny(동물실험 반대, 비건과 별개).

## 3. 기술 리서치 요약

상세는 [03-architecture.md](03-architecture.md), [06-api-and-ml.md](06-api-and-ml.md).

- **프레임워크**: Expo SDK 55+(RN 0.83, New Architecture 전용) + react-native-vision-camera v5(Nitro 모듈, worklet 프레임 프로세서). Flutter는 `camera` 플러그인 이미지 스트림이 platform channel 직렬화 병목([DeepAR 경험](https://www.deepar.ai/blog/deepar-for-flutter-the-journey)). KMP는 카메라/ML 공용 추상화가 없어 1인 개발에 비용 과다.
- **바코드**: Google ML Kit(무료, 온디바이스, 프레임당 15~40ms 추정). Scandit/Dynamsoft는 곡면·저조도에 강하지만 유료, 초기 불필요.
- **이미지 인식**: Vivino = Vuforia 클라우드 이미지 검색. Google Lens = 임베딩 + ANN(ScaNN). 와인 라벨 논문(arXiv 2404.08820)은 ViT + metric learning + 단일 이미지 3D 시점 합성 증강. Off-the-shelf CLIP은 소매 선반 top-1 ~41%, 도메인 파인튜닝 후 ~89%(업계 블로그 수치) → **자체 갤러리 파인튜닝 필수**.
- **임베딩 모델**: 온디바이스 MobileCLIP2-S0(Apple, 11.4M, iPhone NPU ~1.5ms), 서버 DINOv3 ViT-S/16(Meta) 또는 SigLIP2 B/16-256(Apache-2.0).
- **OCR**: ML Kit Text Recognition v2 Korean(온디바이스, 비Latin은 느림), Apple Vision ko-KR, 서버 PaddleOCR PP-OCRv5 korean(라인 정확도 88%, Apache-2.0), Upstage Document OCR($0.0015/page).
- **벡터 DB**: pgvector 0.8(HNSW, halfvec) — 수백만 SKU까지 충분, 메타데이터와 같은 트랜잭션. Qdrant는 1천만+ 시 이전.
- **인증**: Supabase Auth(Kakao 내장, Naver는 custom OAuth2, Apple/Google 네이티브). App Store 4.8: 소셜 로그인 있으면 Sign in with Apple 필수.

## 4. 법규·라이선스 요약

상세는 [08-legal-privacy.md](08-legal-privacy.md).

- "원산지"는 법마다 다름: 농수산물원산지표시법(원료 생산지), 대외무역법(실질적 변형국 = 사실상 제조국), 화장품법(제조업자·책임판매업자 구분 표시).
- 앱이 직접 판매·광고하지 않으면 표시광고법 직접 대상은 아니나, 커머스 제휴 시 "타사 비방" 조항 적용 가능.
- 명예훼손 방어: 사실(성분 포함, 제조국)과 의견(등급) 분리, 출처 귀속형 표현, 정정요청 채널.
- 데이터 라이선스: EWG 상업 이용 금지, Open Food Facts ODbL(share-alike), KCIA·코리안넷 계약 필요, 수입식품정보마루 크롤링 지양.
- 개인정보: 알레르기·임신 여부는 **민감정보** → 별도 동의·암호화.

## 5. 리서치 불확실성 (추가 확인 필요)

1. 화장품 알레르기 25종 정확한 목록·임계치 → 고시 별표 원문(law.go.kr) 확인.
2. 2026년 농식품부 「원산지 표시요령」 개정안 확정 여부(복합원재료·외국산 표시 조항).
3. 사카린·수크랄로스 최신 EFSA ADI 수치 원문.
4. 에너지음료·커피 카페인 함량 공식 조사는 2012~13년 자료 → 라벨 OCR 값 우선.
5. 식품첨가물공전 구조화 데이터 유무 → 없으면 크롤링/수작업.
6. 코리안넷 API 제공 조건·비용.
7. 국내 '스캔다' 앱은 확인되지 않음.
