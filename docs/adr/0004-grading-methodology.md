# ADR-0004: 성분 등급 방법론 — 등급과 근거 수준 분리, 규제기관 1순위

- 상태: 제안
- 날짜: 2026-10-13

## 맥락
화해(EWG 기반)·Yuka(예방적 접근)는 농도를 무시하고 최악 성분으로 제품을 깎아 "케모포비아" 비판을 받음. EWG는 라이선스상 사용 불가. 명예훼손 방어를 위해 사실/의견 분리와 출처가 필요.

## 결정
- 성분별 `grade` 0~3 + `evidence_level`(규제결론/문헌/관찰/동물·세포) + `regulatory_status(KR/EU/US)` + `applies_to_groups`를 분리 저장.
- 1순위 근거: 식약처·EFSA·JECFA·IARC·CosIng·식약처 고시. 편집 목록(20가지 주의성분 등)은 사용 안 함.
- 제품 등급은 단일 점수 대신 **성분 개수 요약**. 영양은 별도 A~E(Nutri-Score 변형, 이름 미사용).
- 모든 등급 레코드에 출처 URL·검토일 필수(DB 제약).

## 결과
- "한 점수"가 없어 공유성은 Yuka보다 낮을 수 있음 → P1에서 요약 점수 실험 가능(방법론 공개 전제).
- KB 유지 비용(분기 점검) 발생.
