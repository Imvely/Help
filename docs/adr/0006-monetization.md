# ADR-0006: 수익 모델 — 프리미엄 구독 + 커머스 제휴 병행

- 상태: 승인 (2026-10-14, 사용자 결정)
- 날짜: 2026-10-14

## 맥락
사용자가 프리미엄과 커머스를 **둘 다** 가기로 결정. 제휴(코리안넷·KCIA·유통사)는 돈이 들거나
구체적 서비스가 보여야 하므로 **시점 미정 — 서비스가 실제로 돌아간 뒤** 재검토.

## 결정
1. **프리미엄(구독)** — Yuka 모델. 무료는 핵심 가치(스캔·결과 카드·OCR·개인화 1인)를 전부 제공.
   유료 혜택: 오프라인 전체 DB, 무제한 히스토리·동기화, 가족 프로필 5+, 카페인·당류 누적 리포트,
   광고 없음(광고를 넣게 될 경우). 결제는 앱 내 결제(StoreKit/Play Billing) → RevenueCat 류로 단순화.
2. **커머스 제휴** — "대체 제품 추천"(P1-2) 카드에 제휴 링크(쿠팡 파트너스·네이버 등). **추천 순위는
   제휴 여부와 무관**하게 성분·원산지 사실로만 정한다. 제휴 링크는 "광고/제휴" 라벨을 붙인다.
3. 둘 다 **M5 이후**(실사용자 확보 후). MVP 코드에는 엔타이틀먼트 플래그(`entitlements: premium`)와
   대체 제품 카드의 `affiliate_url` 필드 자리만 둔다.

## 법적 유의(docs/08 §2)
- 커머스 제휴 링크가 붙는 순간 **표시광고법의 "타사 비방·근거 없는 비교" 조항 적용 가능성**이 생긴다.
  → 대체 제품 추천 이유는 사실(등급 개수·제조국)만 적고, "더 안전하다/좋다" 같은 평가어를 쓰지 않는다.
  → 등급 방법론 공개 페이지를 추천 카드에서 한 탭에 연결.
- 제휴 수익이 추천에 영향을 주지 않는다는 원칙을 앱 내 "추천 기준" 안내와 약관에 명시.

## 결과
- 데이터 모델에 `products.affiliate_links(jsonb)`(P2)와 `users.entitlements`(P2) 추가 예정.
- 수익화 전까지 광고·제휴 없음 → 노노재팬식 "순수 정보" 포지셔닝 유지.
