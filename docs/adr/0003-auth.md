# ADR-0003: 인증 — Supabase Auth + 익명 세션 승격

- 상태: 제안
- 날짜: 2026-10-13

## 맥락
비회원 전 기능 사용 + 로그인 시 저장·동기화. 한국 소셜(Kakao·Naver) 필수, iOS는 Apple 로그인 동등 노출(App Store 4.8).

## 선택지
- Supabase Auth: Kakao 내장, Naver는 Custom OAuth2(프로젝트당 3개), Apple/Google 네이티브, anonymous sign-in → `linkIdentity` 승격, Postgres RLS와 자연 결합.
- Firebase Auth: Kakao/Naver는 Custom Token 직접 구현.
- Clerk: 한국 소셜 미지원, 비용↑.
- 자체 구현: 보안·유지비.

## 결정
Supabase Auth. 앱 첫 실행 시 익명 세션 발급 → 로그인 시 동일 user_id 유지하며 승격, 로컬 히스토리 병합.
