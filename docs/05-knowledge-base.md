# 05. 지식 베이스 — 성분 등급·알레르기·카페인·영양·원산지 규칙

> 이 문서는 앱이 "판단"하는 모든 규칙의 근거입니다. 규칙을 바꿀 때는 반드시 여기부터 고칩니다. 날짜는 2026-10 기준이며, 각 항목에 근거 수준을 솔직하게 적습니다.

## 1. 화해·Yuka는 어떻게 등급을 매기나 (그리고 왜 그대로 따라하지 않나)

### 화해
- **EWG Skin Deep** 점수 1~10(1-2 녹색, 3-6 노랑, 7-10 빨강)을 성분별로 표시. EWG는 **데이터 충분도(None~Robust)**도 함께 내지만 화해 UI에서는 유해성 등급이 전면에 나와 비판받음([여성신문](http://www.womennews.co.kr/news/view.asp?num=112696)). EWG는 가중치 공식을 공개하지 않음.
- **"20가지 주의성분"**은 서적 『대한민국 화장품의 비밀』의 목록. 과학기관 기준이 아니며 업계는 "케모포비아"라 비판([CNC News](https://www.cncnews.co.kr/news/article.html?no=4048)). **근거 수준: 낮음(편집 목록)**.
- **알레르기 유발 주의 성분**: 식약처 고시 착향제 25종(EU 26종에서 사용금지 3종 제외). 임계치: 씻어내는 제품 0.01% 초과, 씻어내지 않는 제품 0.001% 초과.
- **피부타입별 성분**: 대한피부과의사회 가이드 기반. 공식 방법론 문서 없음.

### Yuka
- 식품: Nutri-Score 기반 영양 60 + 첨가물 30 + 유기농 10. **고위험 첨가물 1개 또는 Nutri-Score D/E면 49점 상한.**
- 첨가물 4단계: 무위험 0 / 제한적 위험 −6 / 중위험 −15 / 고위험 −30. 출처는 EFSA·FDA·ANSES·JECFA·IARC + 독립 연구, "예방적 접근" 명시([Yuka help](https://help.yuka.io/l/en/article/yth80j3vle-sources-analysis-of-food-additives)).
- 화장품: 최고위험 성분이 점수를 결정. 농도 미반영([Yuka help](https://help.yuka.io/l/en/article/2t20ixn5y5-evualuation-cosmetic-products)).

### 공통 문제와 우리의 차별점
두 앱 모두 **"유해 가능성(hazard)"을 "실제 위험(risk)"처럼** 보여줍니다. 위험 = 유해성 × 노출량인데, 노출량(농도·섭취량)을 무시합니다. 우리는:
1. `grade`(등급)와 `evidence_level`(근거 수준)을 **분리 저장·표시**.
2. 규제기관(식약처·EFSA·JECFA) 결론을 1순위 근거로, 편집 목록은 "참고 태그"로만.
3. 제품 등급을 "최악 성분 하나"로 깎지 않고 **성분별 개수 요약**(안전 12 · 주의 1 …)으로 보여준다.
4. EWG 데이터는 라이선스상 사용 불가([08-legal-privacy.md](08-legal-privacy.md)).

## 2. 성분 등급 4단계 기준표

| 등급 | 이름 | 기준 | 예 |
|---|---|---|---|
| **0** | 안전 | 식약처·EFSA·JECFA가 ADI 내 안전 결론, 신뢰 가능한 인체 유해 신호 없음 | 아세설팜K, 스테비아, 사카린, 소르빈산, MSG, 구연산 |
| **1** | 주의(조건부) | **특정 집단**에만 문제(어린이·PKU·신장·임신·반려동물) 또는 과량 시 부작용 | 아스파탐(PKU), 당알코올(설사), 인산염(신장), 타르색소(어린이), 카페인 |
| **2** | 논쟁적 | 규제기관은 안전 결론이나 (a) IARC 2B 등 해저드 분류, (b) 관찰연구 신호 반복, (c) 규제기관 간 불일치(EU 금지·KR 허용) | 아스파탐, 에리스리톨, 카라기난, 이산화티타늄(E171), 아질산나트륨(저량) |
| **3** | 유해(회피 권장) | 인체 역학·메커니즘 모두 확립, 국제기구 저감 권고, 또는 사용금지 성분 | 트랜스지방/부분경화유, 가공육 중 아질산염 고노출, 배합금지 성분 |
| **—** | 미확인 | KB에 없음 | 회색 표시, "정보 없음" |

**근거 수준(evidence_level)** 아이콘: 🏛 규제결론 / 📚 체계적 문헌 / 🔬 관찰연구 / 🧪 동물·세포. 등급 2는 대부분 🔬 또는 🧪이며, 이걸 보여주는 것이 "왜 논쟁적인지"의 설명입니다.

모든 레코드 필수 필드: `source_urls`, `last_reviewed`, `summary_ko`(초등학생도 읽을 수 있는 2문장).

## 4. 알레르기

### 식품 — 한국 의무표시 19항목
(식품표시광고법 시행규칙 별표2, 2020.9 개정. "22종"은 조개류를 굴·전복·홍합으로 따로 센 숫자.)

알류(가금류), 우유, 메밀, 땅콩, 대두, 밀, 고등어, 게, 새우, 돼지고기, 복숭아, 토마토, 아황산류(최종제품 SO₂ 10mg/kg 이상), 호두, 닭고기, 쇠고기, 오징어, 조개류(굴·전복·홍합 포함), 잣
([식품안전나라](https://www.foodsafetykorea.go.kr/portal/board/boardDetail.do?menu_no=3120&menu_grp=MENU_NEW01&bbs_no=bbs001&ntctxt_no=1091412))

- 함량 무관, 원재료로 쓰이면 표시. 별도 표시란.
- **혼입 가능**: "이 제품은 ○○를 사용한 제품과 같은 제조시설에서 제조" 문구 → `may_contain`으로 분리 저장. "심한 알레르기" 토글 사용자에게는 혼입 가능도 경고.

### 수입품 매핑
- EU 14종: 글루텐 곡류, 갑각류, 알, 생선, 땅콩, 대두, 우유, 견과류(8종 명시), 셀러리, 겨자, 참깨, 아황산, 루핀, 연체류.
- 미국 9종: 우유, 알, 생선, 갑각류, 견과, 땅콩, 밀, 대두, 참깨(2023).
- 일본 의무 9종: 알, 우유, 밀, 메밀, 땅콩, 새우, 게, 호두(2025), 캐슈(2026).
- 한국 고유: 고등어, 돼지고기, 복숭아, 토마토, 닭고기, 쇠고기, 오징어, 잣.
- 구현: 원자 단위 코드([04-data-model.md](04-data-model.md) §2-3)로 저장하고 국가별 리스트는 매핑. 수입 제품은 "이 나라 기준으로 표시됨, 한국 고유 항목(돼지고기 등)은 미표시일 수 있음" 안내.

### 화장품
- 한국: 착향제 알레르기 유발성분 **25종** 표시 의무(2020~). 정확한 목록·임계치는 고시 별표 원문 확인(불확실성 #1).
- EU: 2023/1545로 26→**81종**, 2026.7.31 신규 출시분부터 적용. 한국 25종은 EU의 부분집합 → 수입 EU 제품은 더 많은 알레르겐이 표기될 수 있음을 안내.

## 5. 카페인

| 항목 | 값 |
|---|---|
| 고카페인 표시 기준 | 액체식품 0.15mg/mL 이상 → "고카페인 함유" + 총 함량 + 주의 문구 의무 |
| 1일 최대 섭취 권고 | 성인 400mg / 임산부 300mg / 어린이·청소년 2.5mg/kg |
| 대표 함량(식약처 과거 조사, 라벨 우선) | 커피믹스 69mg, 캔커피 175mL 74mg, 콜라 250mL 23mg, 녹차 티백 15mg, 초콜릿 30g 16mg, 에너지음료 평균 99mg(최대 164mg), 전문점 아메리카노 100~150mg |

**개인화 계산**
```
limit_mg = 400                        # 기본 성인
if pregnant: limit_mg = 300
if age < 19 and weight_kg: limit_mg = 2.5 * weight_kg
if sensitivity == "sensitive": limit_mg *= 0.5
if sensitivity == "avoid": limit_mg = 0
today_total = sum(scans.today.caffeine_mg where consumed)
warn if product.caffeine_mg > 0.5*limit or today_total + product > limit
```
제품 측 필드: `caffeine_mg_per_serving`, `caffeine_mg_per_100ml`, `high_caffeine(≥0.15mg/mL)`. 함량 출처는 **라벨 OCR 우선**, 없으면 카테고리 평균(출처 "추정" 표시).

## 6. 영양 점수

- **Nutri-Score 2023 개정 알고리즘**(공개): 100g 기준 비호의 점수(에너지·당·포화지방·소금, 최대 55) − 호의 점수(단백질·식이섬유·과채류, 최대 17). 고형 A ≤ −1, B 0~2, C 3~10, D 11~18, E ≥ 19. 음료는 별도 척도 + 인공감미료 페널티([OFF 공식](https://world.openfoodfacts.org/nutriscore-formula)).
- 한국 라벨에 **식이섬유·과채비율이 없음** → 카테고리 기본값으로 추정하고 "추정" 표시. 한식(김치·장류)은 나트륨에 가혹 → 카테고리별 보정을 **문서화해 공개**.
- 상표 문제로 **Nutri-Score 이름·로고는 쓰지 않고** 자체 A~E로 표기.
- 병행 표시: 한국 1일 영양성분 기준치 %(2,000kcal: 나트륨 2,000mg, 당류 100g, 포화지방 15g), 어린이 고열량·저영양 판정(간식 1회 250kcal 초과 & 단백질 2g 미만, 당류 17g 초과 등), 나트륨·당류 저감 표시("덜 짠/덜 단").
