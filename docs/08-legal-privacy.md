# 08. 법규·라이선스·개인정보

> 법률 자문이 아닙니다. 출시 전 변호사 검토가 필요한 항목은 ⚖로 표시합니다.

## 1. "원산지"는 법마다 다르다

| 법 | 원산지의 뜻 | 앱에서의 필드 |
|---|---|---|
| 농수산물의 원산지 표시 등에 관한 법률 | 농수산물이 **생산·채취·포획된 곳**. 가공식품은 배합비율 상위 **3순위**까지 원료 원산지 표시 의무(1개 원료 98% 이상이면 1개, 2개 합 98% 이상이면 2개). 물·첨가물·주정·당류는 제외. 김치는 배추·고춧가루 필수 | `ingredient_origins` |
| 대외무역법(수입 가공식품) | **실질적 변형(HS 6단위 변경)을 가한 국가** → 사실상 제조국. 중국산 원료로 한국에서 제조하면 "국내산" 가능 | `declared_origin_country` |
| 화장품법 §10, 시행규칙 §19④ | 수입화장품은 **제조국·제조회사명·소재지** 기재. **제조업자와 책임판매업자 구분 표시** 의무(OEM 판별 근거). 원료 원산지 의무 없음 | `manufacturing_country`, `brand_owner_*`, `oem_flag` |
| 「원산지 표시요령」(농식품부 고시) | "외국산": 최근 3년 연평균 3개국 이상 변경 원료만 허용. "수입산" 단독 표기는 2017년 이후 원칙 폐지. 2026년 개정 행정예고(복합원재료·외국산 조항) 확인 필요 | 값 `외국산` 허용 |

**구현 원칙**
1. 네 필드를 절대 하나로 합치지 않는다.
2. 표시 의무가 없는 원료는 `unknown` → "알 수 없음". **"중국산 아님"으로 추정하지 않는다.**
3. 모든 원산지 값에 `source`(식약처 신고 / 라벨 OCR / 제보)와 `confidence`를 붙여 UI에 노출.

## 2. 표시광고법·명예훼손 방어 ⚖

- **식품표시광고법·표시광고법**: 앱이 직접 판매·광고하지 않으면 직접 대상이 아님. 단, **커머스 제휴 링크**를 넣는 순간 "타사 비방 표시·광고", "객관적 근거 없는 비교" 조항(5년 이하 징역/5천만원 이하 벌금)이 적용될 수 있음. 대법원은 "현실적으로 존재하는 우려"를 표현한 비교는 비방으로 보지 않음([법률신문](https://www.lawtimes.co.kr/news/196523)).
- **명예훼손·업무방해**: 형법 310조 "진실한 사실 + 오로지 공익"이면 위법성 조각. 핵심:
  1. **사실과 의견 분리** — "아스파탐 함유"(사실) vs "등급 2 논쟁적"(의견, 방법론 공개).
  2. **사실은 근거 보관** — 공공데이터 raw, 라벨 사진, 제보 로그를 보존.
  3. **출처 귀속형 표현** — "중국산" 대신 "제조국: 중국(식약처 수입신고 기준)".
  4. **정정 채널** — 기업·사용자 모두 72시간 내 1차 답변, 처리 이력 공개. 노노재팬이 쿠팡·다이소를 일본기업으로 오등재해 소동이 난 사례([데일리안](https://m.dailian.co.kr/news/view/814870))를 반복하지 않는다.
- **화해의 처신 참고**: "정보를 정리해 보여줄 뿐 좋다/나쁘다를 판단하지 않는다", 등급을 외부 출처(EWG·협회 사전)에 귀속, "성분 포함이 최종 제품의 효과를 보장하지 않는다" 문구. 그럼에도 업계 반발이 크므로 우리는 **규제기관 근거 1순위**로 간다.

### 면책·안내 문구 초안
- 결과 카드 하단: "출처: ○○ · 정보가 틀리면 알려주세요"
- 원산지 탭: "원산지·제조국은 안전이나 품질을 뜻하지 않습니다. 표시 의무가 없는 원료는 '알 수 없음'으로 표시합니다."
- 성분 탭: "등급은 식약처·EFSA·JECFA 등 규제기관 결론과 공개 문헌을 바탕으로 한 참고 정보이며 의학적 조언이 아닙니다. 근거 수준을 함께 확인하세요."
- 프로필: "개인화 경고는 입력하신 정보와 제품 표시를 대조한 결과이며, 알레르기 등 건강 문제는 반드시 전문가와 상담하세요."

## 4. 개인정보(PIPA) ⚖

- **알레르기·임신·질환 = 민감정보**(개인정보보호법 §23 건강에 관한 정보). 다른 동의와 **분리된 별도 동의**, 안전성 확보조치 의무. 2026-09-11 시행 §23③(공개 가능성 고지) 반영.
- 설계:
  1. 프로필은 **기본 기기 로컬**(Keychain/Keystore). 서버 동기화는 opt-in.
  2. 서버 저장 시 **컬럼 단위 암호화**(pgcrypto/KMS), 검색 불가 구조, 로그 마스킹.
  3. 판정은 기기에서 → 서버는 사용자 알레르기를 몰라도 됨.
  4. 가족 프로필(자녀)은 법정대리인 동의 흐름(만 14세 미만).
  5. 삭제 요청 시 프로필·히스토리 즉시 삭제, 기여 이미지는 비식별화 후 보존 여부 동의로 결정.
- **카메라 프레임 기여**: 바코드 세션 프레임 업로드는 명시적 동의(온보딩 토글), 얼굴·배경이 찍힐 수 있으므로 320px 축소 + 제품 영역 크롭 후 전송, 보존 목적·기간 고지.
- 비회원 익명 세션 ID는 기기 재설치 시 소멸, 광고 식별자 미사용.
